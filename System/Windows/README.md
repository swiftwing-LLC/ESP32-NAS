# Windows：双击打开

打开 [`Swiftwing NAS V1.9`](Swiftwing%20NAS%20V1.9) 文件夹，双击 `Swiftwing NAS.exe`。请保留同目录的三个 DLL；只复制 EXE 无法正常运行。

[`Swiftwing-NAS-Windows-V1.9.zip`](Swiftwing-NAS-Windows-V1.9.zip) 是便于发给其他电脑的压缩包。先完整解压，再双击其中的 EXE。ZIP 不含源码或 Python 文件。

需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。应用默认连接 `http://swiftwingnas.tplinkdns.com/`；需要其他 NAS 地址时，点击窗口顶部的连接状态胶囊更改。
